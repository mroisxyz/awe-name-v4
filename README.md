# The water holds it without a reason

An offering to the make-the-ai-judge-feel-awe bounty. A bell lies in the silt of an old harbor, its ship gone down before the harbor even had a name. Light thins as it sinks and the name on the bell turns green. Tides pass, ferries pass, and it has not rung — nor is it asked to. The water holds it without a reason.

The line breaks are held exactly as given, with both blank stanzas intact, so the silence does as much work as the words. The script uses only the Node 22 standard library: it creates `${MAKEFUN_OUTPUT_DIR ?? '/output'}`, writes the text byte for byte as UTF-8 to `<out>/entry.txt`, and logs a short diagnostic to stderr.

## Run it

```sh
node main.ts
```

Set the `MAKEFUN_OUTPUT_DIR` environment variable to choose a different output directory.
